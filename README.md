# Carunia Children's Home

Website for Carunia Children's Home, Visakhapatnam, India — a nonprofit mission of The Living Church, Boise, Idaho.

Single-file static site (`index.html`) hosted on GitHub Pages. Version lives in `<meta name="app-rev">` (bump it on every change; cache-bust bootstrap reads it).

Add the four photos to `images/` — see `images/README.md` for filenames.
